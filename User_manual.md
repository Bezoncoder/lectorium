```text
LECTORIUM_USER_MANUAL.md
```

Он описывает текущую многокурсовую модель: курсы, потоки, расписание, видео, доступы, прогресс, админку и создание студентов.

```md
# Lectorium — руководство пользователя

Lectorium — закрытая учебная платформа для проведения курсов с потоками, расписанием, видеозаписями и отслеживанием прогресса студентов.

В системе есть две роли:

- **Студент** — видит только назначенные ему курсы, расписание своего потока и доступные записи.
- **Администратор** — создаёт курсы и потоки, управляет расписанием, видео, студентами, доступами и статистикой.

---

# Основные понятия

## Курс

Курс — образовательная программа.

Примеры:

```text
Python Backend
Data Engineering
ClickHouse
```

У курса есть:

- название;
- описание;
- признак активности;
- один или несколько потоков.

Сам курс не содержит расписания и Telemost. Эти данные относятся к конкретному потоку.

## Поток

Поток — конкретный запуск курса для определённой группы студентов.

Примеры:

```text
Осень 2026 · группа А
Осень 2026 · группа Б
Зима 2027 · вечерняя группа
```

У потока есть:

- название;
- дата начала;
- дата окончания;
- часовой пояс;
- ссылка на Telemost;
- статус;
- собственное расписание;
- собственные видеозаписи;
- список зачисленных студентов.

## Правила доступа

```text
Один курс → много потоков.
Один поток → один курс.
Один студент → один поток в рамках одного курса.
Один студент → несколько курсов.
```

Студент выбирает в личном кабинете только курс.

Поток студент не выбирает: система сама определяет его поток по зачислению.

Студент не видит:

- чужие потоки;
- чужие расписания;
- чужие видеозаписи;
- статистику других студентов;
- админские страницы.

# Статусы

## Статус курса

У курса есть флаг активности:

| Статус | Значение |
|---|---|
| Активен | Курс доступен для использования и новых зачислений |
| Скрыт | Курс выключен для новых зачислений |

Отключение курса не удаляет данные и не обязательно закрывает доступ уже зачисленным студентам.

## Статус потока

| Статус | Значение |
|---|---|
| Черновик | Поток подготовлен, но не используется для зачисления |
| Активен | Текущий или будущий поток, в который можно зачислять новых студентов |
| Завершён | Обучение закончено, но студенты сохраняют доступ к материалам |
| Архив | Старый поток, не предназначенный для текущей работы |

Только поток со статусом **«Активен»** может быть автоматически выбран при назначении студента.

## Статус доступа студента

Доступ конкретного студента хранится отдельно от статуса потока.

| Статус | Доступ к курсу |
|---|---|
| `active` | Есть доступ |
| `completed` | Есть доступ, курс завершён студентом |
| `blocked` | Нет доступа |
| `cancelled` | Нет доступа |

# Руководство для студента

## Вход

1. Откройте страницу входа:

```text
/login
```

2. Введите логин и пароль, полученные от администратора.
3. После входа откроется страница **«Мои курсы»**.

Если вы забыли пароль, обратитесь к администратору. Самостоятельного восстановления пароля в текущей версии нет.

## Мои курсы

На главной странице студент видит только курсы, в которые он зачислен.

Для каждого курса отображаются:

- название;
- описание;
- название назначенного потока;
- статус потока;
- текущий прогресс;
- количество просмотренных занятий;
- ближайшая лекция;
- кнопка **«Открыть курс»**.

Если курсов пока нет, отображается сообщение:

```text
У вас пока нет доступных курсов.
Администратор назначит вас в поток курса.
```

## Просмотр расписания

1. На главной странице нажмите **«Открыть курс»**.
2. Откроется кабинет выбранного курса.
3. В кабинете отображаются:
   - название курса;
   - название потока;
   - период потока;
   - часовой пояс;
   - Telemost, если администратор добавил ссылку;
   - прогресс;
   - ближайшее занятие;
   - полное расписание.

### Статусы занятий

| Статус | Что означает |
|---|---|
| Лекция просмотрена | Запись была просмотрена и засчитана |
| Запись лекции доступна | Видео можно открыть и посмотреть |
| Занятие состоится | Лекция ещё не началась |
| Запись появится после проведения занятия | Занятие прошло или запланировано, но запись ещё не добавлена |

## Telemost

Если для потока добавлена ссылка Telemost:

- в верхней части курса отображается кнопка **«Открыть Telemost»**;
- у будущей лекции может отображаться кнопка **«На встречу»**.

Ссылка открывается в новой вкладке браузера.

## Просмотр видео

Видео можно открыть:

- кнопкой **«Смотреть запись»** рядом с занятием;
- через кнопку **«Видео курса»**;
- через раздел **«Все записи»** в карточке прогресса.

Студент видит только видеозаписи своего потока.

После открытия записи:

1. Видео запускается в браузерном плеере.
2. После просмотра не менее 15 секунд система регистрирует просмотр.
3. Внизу страницы появится блок **«Мои просмотры»**.
4. После обновления страницы или возврата в курс будет обновлён прогресс.

### Мои просмотры

Под видеоплеером отображается:

- количество засчитанных просмотров;
- дата и время последнего просмотра.

Просмотр засчитывается после 15 секунд.

Повторные просмотры разрешены. При подсчёте прогресса одна запись засчитывается только один раз.

## Прогресс

Прогресс рассчитывается отдельно для каждого курса и назначенного студенту потока.

Формула:

```text
Прогресс = просмотренные занятия / все занятия потока × 100%
```

Пример:

```text
Всего занятий: 10
Просмотрено: 4
Прогресс: 40%
```

Если в расписании есть занятие без видео, оно не может быть отмечено как просмотренное до публикации записи.

## Завершённые курсы

После завершения потока студент сохраняет доступ к курсу, расписанию, видеозаписям и своему прогрессу.

Нельзя потерять доступ к завершённому курсу, если администратор не заблокировал или не отменил зачисление.

# Управление курсами

## Открыть список курсов

Откройте:

```text
/admin/courses
```

Или используйте пункт меню **«Курсы»**.

В списке отображаются:

- название курса;
- описание;
- количество потоков;
- статус курса;
- кнопка управления.

## Создать курс

1. Откройте **«Курсы»**.
2. Нажмите **«Создать курс»**.
3. Заполните:
   - название курса;
   - описание;
   - флаг «Курс доступен для новых зачислений».
4. Нажмите **«Создать курс»**.

После создания откроется страница курса.

## Редактировать курс

1. Откройте нужный курс.
2. Нажмите **«Редактировать курс»**.
3. Измените название, описание или активность.
4. Нажмите **«Сохранить»**.

Курс лучше не удалять физически, если в нём есть потоки, студенты, видео и история обучения.

# Управление потоками

## Создать поток

1. Откройте курс.
2. В блоке **«Добавить поток»** заполните:
   - название потока;
   - дату начала;
   - дату окончания;
   - часовой пояс;
   - Telemost;
   - статус.
3. Нажмите **«Создать поток»**.

Пример:

```text
Название: Осень 2026 · группа А
Дата начала: 01.09.2026
Дата окончания: 29.10.2026
Часовой пояс: Europe/Moscow
Статус: Активен
```

## Настроить поток

1. Откройте курс.
2. Выберите нужный поток.
3. В блоке **«Настройки потока»** можно изменить:
   - название;
   - даты;
   - часовой пояс;
   - Telemost;
   - статус.
4. Нажмите **«Сохранить поток»**.

## Когда ставить статус «Активен»

Поток должен иметь статус **«Активен»**, если:

- в него нужно добавлять новых студентов;
- он является текущим потоком;
- он должен автоматически выбираться системой при назначении студента без явного `stream_id`.

Если у курса нет активного потока, автоматическое назначение выдаст сообщение:

```text
Для курса нет активного или ближайшего потока.
```

## Завершение потока

Потоки не переходят в статус «Завершён» автоматически после даты окончания.

Администратор должен изменить статус вручную:

```text
Активен → Завершён
```

После завершения:

- новые студенты не назначаются автоматически в этот поток;
- существующие студенты сохраняют доступ к материалам;
- поток остаётся в статистике и истории.

# Управление расписанием

Расписание всегда относится к конкретному потоку.

## Добавить занятие

1. Откройте поток.
2. В блоке **«Добавить занятие»** заполните:
   - название лекции;
   - дату и время;
   - запись видео, если она уже загружена.
3. Нажмите **«Добавить лекцию»**.

Если запись ещё не загружена, оставьте поле видео пустым.

## Редактировать занятие

В списке занятий можно изменить:

- название;
- дату и время;
- связанную запись видео;
- порядок.

После изменений нажмите **«Сохранить»** у нужного занятия.

## Удалить занятие

Нажмите **«Удалить»** справа от нужного занятия.

Удаление занятия:

- удаляет только пункт расписания;
- не удаляет видеофайл;
- не удаляет запись из таблицы видео;
- не удаляет студентов и их зачисления.

## Очистить расписание

Кнопка **«Очистить расписание»** удаляет все занятия текущего потока.

Она не удаляет:

- видеозаписи потока;
- пользователей;
- зачисления;
- историю просмотров.

---

# Управление видео

Видео всегда принадлежит конкретному потоку.

## Загрузить видео

1. Откройте нужный поток.
2. Нажмите **«Видео потока»**.
3. Нажмите **«Добавить видео»**.
4. Укажите:
   - название;
   - описание;
   - видеофайл.
5. Нажмите **«Загрузить»**.

Поддерживаются:

```text
MP4
WebM
OGG / OGV
```

После загрузки видео доступно только студентам, зачисленным в этот поток.

## Привязать видео к занятию

1. Откройте поток.
2. Найдите нужную лекцию в расписании.
3. В поле **«Запись видео»** выберите загруженный ролик.
4. Нажмите **«Сохранить»**.

Один ролик можно привязать только к одному занятию.

## Посмотреть видео как администратор

1. Откройте:

```text
Курсы → курс → поток → Видео потока
```

2. Нажмите **«Смотреть»**.

Видео откроется в той же вкладке.

Кнопка у плеера:

```text
К видео потока
```

вернёт в административный список видео текущего потока.

Просмотр администратора не влияет на учебный прогресс студентов и не добавляется в статистику просмотров.

## Редактировать видео

В списке видео потока нажмите **«Изменить»**.

Можно изменить:

- название;
- описание.

Сам видеофайл не заменяется через текущую форму. Для замены файла загрузите новую запись и привяжите её к занятию.

## Удалить видео

Нажмите **«Удалить»** рядом с записью.

При удалении:

- удаляется строка из `videos`;
- удаляется файл из каталога `video/`;
- удаляются связанные просмотры из `video_views`;
- у связанного занятия `video_id` становится `NULL`;
- занятие остаётся в расписании.

# Управление студентами

## Найти студента

1. Откройте раздел **«Студенты»**:

```text
/admin/students
```

2. Введите логин.
3. Нажмите **«Найти»**.
4. Нажмите **«Открыть карточку»**.

## Создать студента без курса

Можно использовать Python-скрипт:

```text
scripts/create_student_without_cource.py
```

Пример:

```python
import asyncio

from app.services.auth import UserService


async def create_student(
    login: str,
    password: str,
) -> None:
    student = await UserService.create_student(
        login=login,
        password=password,
    )

    if student is None:
        print(f"Пользователь '{login}' уже существует")
        return

    print(
        f"Студент создан: "
        f"id={student.id}, "
        f"login={student.login}"
    )


if __name__ == "__main__":
    asyncio.run(
        create_student(
            login="student5",
            password="student5",
        )
    )
```

Запуск:

```bash
python scripts/create_student_without_cource.py
```

Такой студент может войти в систему, но не увидит курсы, пока администратор не назначит ему поток.

## Назначить курс студенту вручную

1. Найдите студента.
2. Откройте карточку студента.
3. В блоке **«Назначить курс»** выберите курс.
4. Выберите поток вручную либо оставьте поле пустым.
5. Нажмите **«Назначить»**.

Если поток не выбран, система автоматически выберет:

1. текущий активный поток;
2. если его нет — ближайший будущий активный поток;
3. если есть активный поток без дат — его.

Если у курса нет активного потока, сначала переведите нужный поток в статус **«Активен»**.

## Изменить пароль студента

1. Найдите и откройте карточку студента.
2. В блоке **«Сменить пароль»** введите новый пароль.
3. Нажмите **«Сменить пароль»**.

После смены пароля:

- старый пароль перестаёт работать;
- все активные сессии студента завершаются;
- студент должен войти заново.

# Создание студента через API

API доступен только авторизованному администратору.

```text
POST /admin/api/students
```

## Создание с явно указанным потоком

```json
{
  "login": "student_01",
  "password": "StrongPassword123",
  "course_id": 2,
  "stream_id": 5
}
```

Система проверяет:

- существует ли курс;
- существует ли поток;
- принадлежит ли поток этому курсу;
- имеет ли поток статус `active`;
- свободен ли логин.

## Создание с автоматическим подбором потока

```json
{
  "login": "student_02",
  "password": "StrongPassword123",
  "course_id": 2
}
```

Если `stream_id` не передан, система выбирает подходящий активный поток автоматически.

## Успешный ответ

```json
{
  "user": {
    "id": 15,
    "login": "student_02",
    "role": "student"
  },
  "course": {
    "id": 2,
    "title": "Python Backend"
  },
  "stream": {
    "id": 5,
    "title": "Осень 2026 · группа А",
    "selection_source": "auto"
  },
  "enrollment": {
    "id": 18,
    "status": "active"
  }
}
```

# Статистика просмотров

Раздел доступен только администратору:

```text
/statistics
```

Статистика показывает:

- курс;
- поток;
- видео;
- общее число просмотров;
- число уникальных зрителей;
- дату последнего просмотра;
- список студентов, смотревших конкретную запись.

Просмотр учитывается после 15 секунд.

Студент не имеет доступа к общей статистике. На странице видео студент видит только собственные просмотры.

# Частые проблемы

## Студент не видит курс

Проверьте:

1. Студент существует.
2. У него есть запись в `stream_enrollments`.
3. Выбран правильный курс.
4. Поток существует.
5. Статус зачисления студента — `active` или `completed`.

## Невозможно добавить студента автоматически

Ошибка:

```text
Для курса нет активного или ближайшего потока.
```

Решение:

1. Откройте нужный курс.
2. Откройте поток.
3. В настройках измените статус на **«Активен»**.
4. Проверьте даты потока.
5. Повторите назначение студента.

## Студент не видит видео

Проверьте:

1. Видео принадлежит нужному потоку.
2. Студент зачислен именно в этот поток.
3. У зачисления статус `active` или `completed`.
4. Видео существует в таблице `videos`.
5. Файл существует в каталоге `video/`.

## Видео не засчитывается в прогресс

Проверьте:

1. Студент посмотрел не менее 15 секунд.
2. В `video_views` появилась запись.
3. Видео привязано к занятию.
4. Видео и занятие принадлежат одному потоку.
5. Студент обновил страницу курса.

## Администратор не может открыть видео

Откройте:

```text
Курсы → курс → поток → Видео потока → Смотреть
```

Администратор имеет доступ ко всем видео и не должен быть зачислен в поток.

## Старые стили остаются после обновления

Сделайте жёсткое обновление страницы:

```text
Ctrl + Shift + R
```

Если нужно, временно добавьте версию к CSS в `base.html`:

```html
<link
  rel="stylesheet"
  href="{{ url_for('static', path='css/style.css') }}?v=2"
>
```

PostgreSQL
Каталог video/
Конфигурацию .env

```bash
pg_dump \
  -U lectorium \

tar -czf backup_video_$(date +%F).tar.gz video/
